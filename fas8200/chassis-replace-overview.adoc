= FAS8200 시스템에서 섀시를 교체하기 위한 요구 사항을 검토하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS8200 시스템의 섀시를 교체하기 전에 다른 모든 구성 요소가 제대로 작동하는지, 그리고 교체할 섀시가 NetApp에서 제공하는 동일 모델의 새 제품인지 확인하십시오. 이 절차에는 전원 공급 장치, 팬 및 컨트롤러 모듈을 새 섀시로 이동하는 작업이 포함되며, 2개 컨트롤러로 구성된 클러스터에서는 전체 서비스 중단이, 다중 노드 클러스터에서는 부분적인 서비스 중단이 발생할 수 있습니다.

시스템의 다른 모든 구성 요소가 제대로 작동해야 합니다. 그렇지 않은 경우 기술 지원 부서에 문의하십시오.

* 이 절차는 시스템에서 지원하는 모든 버전의 ONTAP에서 사용할 수 있습니다.
* 이 절차는 컨트롤러 모듈 또는 모듈을 새 섀시로 이동하는 가정과 NetApp의 새 구성 요소로 이루어져 있습니다.
* 이 절차는 서비스 중단을 초래합니다. 컨트롤러가 두 개인 클러스터의 경우 전체 서비스 중단이 발생하고, 다중 노드 클러스터의 경우 부분적인 서비스 중단이 발생합니다.
