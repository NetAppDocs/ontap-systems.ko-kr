= FAS9000 시스템에 X91148A 모듈을 추가하는 방법에 대해 알아보십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS9000 시스템에 X91148A 모듈을 추가하려면, 완전히 장착된 시스템에서 NIC 또는 스토리지 어댑터를 새 제품으로 교체하거나, 빈 섀시 슬롯에 새 NIC 또는 스토리지 어댑터를 추가하면 됩니다.

NIC 또는 스토리지 어댑터를 완전히 채워진 시스템의 새 NIC 또는 스토리지 어댑터로 교체하거나 시스템의 빈 섀시 슬롯에 새 NIC 또는 스토리지 어댑터를 추가하여 시스템에 입출력 모듈을 추가할 수 있습니다.

.시작하기 전에
*  https://hwu.netapp.com["NetApp Hardware Universe를 참조하십시오"]를 확인하여 새 I/O 모듈이 시스템 및 실행 중인 ONTAP 버전과 호환되는지 확인하십시오.
* 사용 가능한 슬롯이 여러 개인 경우  https://hwu.netapp.com["NetApp Hardware Universe를 참조하십시오"]에서 슬롯 우선순위를 확인하고 I/O 모듈에 가장 적합한 슬롯을 사용하십시오.
* 입출력 모듈을 무중단으로 추가하려면 타겟 컨트롤러를 인수하고, 타겟 슬롯에서 슬롯 블랭킹 커버를 제거하거나, 기존 I/O 모듈을 제거하고, 새 입출력 모듈 또는 교체 입출력 모듈을 추가한 다음 타겟 컨트롤러를 반환해야 합니다.
* 다른 모든 구성 요소가 제대로 작동하는지 확인합니다.
