= 수동 부팅 복구 프로세스를 완료한 후 장애가 발생한 AFF A800 부팅 미디어를 NetApp으로 반환하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AFF A800 시스템에서 부팅 미디어 오류에 대한 수동 부팅 복구 프로세스를 완료한 후, 오류가 발생한 부품을 NetApp에 반환하십시오. 자세한 내용은 https://mysupport.netapp.com/site/info/rma["부품 반환 및 교체"] 페이지를 참조하십시오.
