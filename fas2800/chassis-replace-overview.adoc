= FAS2820 시스템에서 섀시를 교체하기 위한 요구 사항을 검토하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS2820 시스템의 섀시를 교체하려면 전원 공급 장치, 하드 드라이브 및 컨트롤러 모듈을 고장난 섀시에서 새 섀시로 이동합니다. 그런 다음 고장난 섀시를 장비 랙이나 시스템 캐비닛에서 꺼내고 동일 모델의 새 섀시를 그 자리에 설치하십시오.

시스템의 다른 모든 구성 요소가 제대로 작동해야 합니다. 그렇지 않은 경우 기술 지원 부서에 문의하십시오.

* 이 절차는 시스템에서 지원하는 모든 버전의 ONTAP에서 사용할 수 있습니다.
* 이 절차는 모든 드라이브 및 컨트롤러 모듈 또는 모듈을 새 섀시로 이동하는 가정과 NetApp의 새 구성 요소로 구성됩니다.
* 이 절차는 서비스 중단을 초래합니다. 컨트롤러가 두 개인 클러스터의 경우 이 절차로 인해 서비스가 완전히 중단되고, 여러 노드로 구성된 클러스터에서는 부분적인 서비스 중단이 발생합니다.
