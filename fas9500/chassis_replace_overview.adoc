= FAS9500 시스템에서 섀시를 교체하기 위한 요구 사항을 검토하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
섀시를 교체하려면 전원 공급 장치, 팬, 컨트롤러 모듈, I/O 모듈, DCPM 모듈을 분리해야 합니다. 손상된 섀시에서 USB LED 모듈을 꺼낸 후, 손상된 섀시를 장비 랙 또는 시스템 캐비닛에서 분리하고, 교체 섀시를 제자리에 설치한 다음 구성 요소를 교체 섀시에 설치합니다.

.시작하기 전에
시스템의 다른 모든 구성 요소가 제대로 작동해야 합니다. 그렇지 않은 경우 기술 지원 부서에 문의하십시오.

.이 작업에 대해
* 이 절차는 시스템에서 지원하는 모든 버전의 ONTAP에서 사용할 수 있습니다.
* 이 절차는 서비스 중단을 초래합니다. 2노드 클러스터의 경우 완전한 서비스 중단이 발생하며, 다중 노드 클러스터의 경우 부분적인 서비스 중단이 발생합니다.
